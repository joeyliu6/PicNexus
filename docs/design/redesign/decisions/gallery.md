# 设计没画、开发时补的（图库）

> 读者：维护者，以及改这一页的 AI。阶段 4（G01–G13 K02 K03 K07）实施时按交接说明的规则自行补的做法；全部阶段做完后统一请维护者过目。入口见 [README](../README.md)。

- 历史、时间轴、收藏三个旧页合成图库一页：收藏是筛选条件之一（「★ 收藏」），列表与网格用同一份筛选。
- 「状态」只勾了「失效」时，网格不按天分，分「失效 · 有可用备份」「失效 · 无可用备份」两组（照 G06 / G07，不照交接说明 8.2 的按天分组），组名旁写张数，空的那组不出现；勾了别的状态或几项一起勾仍按天分，列表视图不分组。有可用备份 = 别的图床上还有一份没被查出失效（正常、尚未检测、可能受限都算），与详情顶上的提示同一口径。两组一次读全，没有刻度条，灯箱 ← → 按两组眼前的顺序翻（`useDeadSections`）。
- 详情面板右上角（收藏旁）有 ×：点它、`Esc`、再点一次正开着的那张都收起。不放预览图（设计稿 G05 的大图去掉）：图就在左边的网格 / 列表里，看大图双击它。链接块只占一行、过长省略（悬停看全文），「复制」与它同高。详情与列表的滚动条平时透明、鼠标移上去才露出，不和分隔线并排成两道竖线。
- 双击开灯箱，第一下打开的详情留着；第一下打开详情后网格变窄重排，500 ms 内的第二下落到别的格子上时，开的仍是第一下点的那张。
- 打开详情、网格变窄重排时：停在最顶上就留在最顶上（G05），否则视口中间那张留在原位置。
- 行高照 GalleryScreen 用 150，窄窗口也是 150（K02 / K03 两张画板都画的 150；ImageRatios G13 说明里的「窄窗口 120」不照做）。
- 页面一直开着跨过午夜：「今天 / 昨天」在午夜和每次切回图库时按当天重算。
- 换筛选（含搜索、「失效」两组与按天互换）：新结果连同第一屏的图读好之前，网格、计数、空状态都留着上一次的，读好后一次换上，新结果从最上面看起；不闪只有日期标题的空网格、整屏灰块、「共 0 张」「暂无图片」（LoadingRules ①）。网格里加载过的缩略图再出现时直接显示，不再从占位色淡入。
- 图库开着时记录有变化（上传、补充备份、改用、重新检测等）：张数变了的那天先留着原来的格子，新记录读回来再与新的计数一起换上，已有的图不先变成灰块；当天第一次上传，新的一天读回来才出现在最上面。
- 列表的排序在网格 / 列表之间切换时保留。换排序或筛选同网格：新的第一页读回来之前留着旧的行，读好后连同计数、空状态一次换上，从最上面看起；记录有变化时屏幕上的行也留着，重读回来原地换，不先变成骨架条。
- `Ctrl/⌘ A` 全选当前筛选下的全部结果，不只是已经加载出来的那几天。
- 花瓣只数份数，一份一片、全是品牌蓝（同 GalleryScreen）；哪份有问题由 ⚠ 角标、详情与灯箱顶栏说。
- 重新检测：查出失效时通知用琥珀色（需要留意的状态），全部正常才是绿色的成功。
- 详情的图床行：尚未检测、可能受限的那份也能复制，只有「图片已不存在」的不给复制；⋯ 菜单是「改用这一份 / 重新检测 / 在浏览器打开 / 移除这条链接…」（移除前确认）。
- 列表行的 ⋯ 菜单：查看详情 / 查看大图 / 在浏览器打开 / 移除记录；列数按列表自己的宽度定（打开详情、收起侧栏都会变）：窄于 1080px 去掉「尺寸 · 大小」，窄于 820px 再把图床写到文件名下面一行、「状态」收成文件名旁的 ⚠（只剩缩略图 · 文件名 · 上传时间 · 操作），文件名始终有地方显示。
- 「移除记录」不弹确认（能撤销的不确认；STATES G04 写的「先确认」不照做），通知「已移除 N 条记录 · 图床上的图片不受影响」带「撤销」（原样插回，含收藏与检测结果）。
- 多选栏「复制链接 ▾」按 CopyMulti ③：先选格式，再选「复制时使用的链接」或指定从哪个图床复制；失效的链接不复制（CopyMulti：失效的置灰、不能点），没有可用链接的跳过并在通知里写张数。
- 灯箱这次没加载出来：只有检测确认失效的那份照 G08 写「X链接已失效」「X上的图片已不存在」；断网、超时、没检测过的写「X图片加载失败，可切换图床查看」「X上的图片加载失败」（「图片加载失败」取自 Patterns），不把一次加载失败说成检测结论。读不出这张图的记录（打开、翻页时）通知「未能打开大图」+ 原因 +「请重试」。
- 灯箱：「换个图床」只换这次看的那份，不改「复制时使用」；底栏不放「信息」按钮、没有 `I` 键（文件名、尺寸、大小、图床已写在底栏，跳去详情会先把大图缩回去）；滚轮缩放，不换图。菜单开着时 `Esc` 只关菜单、方向键在菜单里走。从列表打开时 ← → 按列表眼前的顺序翻，「3 / 21」是列表里的第几行。
- 不同比例（G13）：长图格子只写「长图」（1:2.5 的格子只有 48–60 px 宽，放不下画板上的「长图 1:5.6」，说明文字本来就写「标『长图』」）；短边小于 120 的小图优先于长图 / 全景的规则（裁切格会把图标、徽章放大得更糊）；同一角放不下两个角标时健康角标优先（「长图」与原尺寸让位，全景的比例留着）。
- 透明：数据库没记每张图是否真透明，按格式判断，JPEG 以外都在图片底下衬棋盘格（不透明的图会把它整个盖住）。动图只认 GIF：动态 WebP 从扩展名看不出来，按静态图显示。
- 预览框（详情、首页焦点卡）按 G13 的规则用这张图的模糊放大版填空白（G05 与首页画板画的是灰底，以 G13 的专门规则为准）；原图比框小时不放大。
- 灯箱里的长图（高宽比超过 2.5）：按窗口宽度、不超过原尺寸从顶部显示，滚轮上下滚动，`Ctrl`+滚轮缩放，点一下看全貌。
- 在「★ 收藏」筛选下取消收藏：那张留在原处（星标变空），重新进筛选才消失，免得点完图跳走。
- 命令面板 `Ctrl+Enter` / `⌘Enter`「在图库中定位」：回到网格、清掉会把它筛掉的条件，跳到它那一天，选中并打开详情。
- 刻度条拖动经过很多个月时只跳最后停下的那个月（跳转中的请求只留最后一个）。点年份跳到这一年最新的那个月（年份写在它各月之上，代表这一年最近的部分）。
- 键盘与读屏：网格只有一个 Tab 停留点（详情 / 焦点那张，没有就是视口里第一张），方向键走、焦点跟着走；Enter 详情、空格灯箱。读屏看到「日期行 → 图片行 → 格子」，格子读文件名，再读 ⚠ 状态、已收藏、长图 / 全景 / 原尺寸、GIF。刻度条排在图片之后，Tab 到时浮出并显示当前月的气泡，↑ ↓ 换一格、PageUp / PageDown 一次 5 格、Home / End 到最新 / 最旧。列表同样只有一个 Tab 停留点，↑ ↓ / Home / End / PageUp / PageDown 换行，Enter 详情、空格灯箱；这一行的「复制」「⋯」接在它后面。
- 键盘不能单独选中某一张（设计没给按键，空格已是灯箱）：多选靠鼠标（Ctrl / Shift 单击）或 `Ctrl/⌘ A` 全选。
- 格子窄到放不下角标时（窄窗口打开详情，长图格子可能只剩 20 多 px）：长图 / 全景 / 原尺寸不画，⚠ 角标只留 ⚠，「仅 1 份」不画；窄到连 ⚠ 都放不下（约 33px 以下）就什么角标都不画。读屏与详情照常说明。
- 灯箱开关：打开 250 ms、关闭 175 ms（交接说明 5.3「舒展」、退场快 30%）；两头都用快启慢停的曲线，不用 5.3 的退场曲线：关闭是把图收回到缩略图位置，退场曲线最后一段最快，图会「啪」地吸进去。
- 灯箱的顶栏、底栏是实心深色底：长图、放大的图平移时从它们下面经过，不盖住按钮；窄窗口里底栏按钮不折行，文件信息与图床名放不下时以「…」截断。
- 空状态的尺寸（说明文字 13px、各段间距）以图库 G09–G11 为准，所有页面的空状态共用这一份；Patterns 画板里的空状态略有出入。
- 预览框的模糊衬底不跟「减少视觉效果」开关走：只有详情与首页焦点卡两处、面积小。
- Markdown 格式方括号里的说明去掉扩展名（`![截图](…)`，照设计稿；`markdownAlt`），首页、图库、托盘共用同一个格式器；HTML 的 `alt`、自定义模板的 `{filename}` 仍是完整文件名，Obsidian 插件插入笔记的写法另算。
- 搜索：打字 0.2 秒后才筛，文件名包含即可、不分大小写；搜索框里按 Esc 清空。
- 「状态」菜单四项：失效、可能受限、仅 1 份、尚未检测；勾选后菜单不收起，勾多项时符合任一即可，看的是「复制时使用」那份的状态；筛选条上多个状态合成一个标签，点一次 × 全部去掉。「时间」四档：不限、最近 7 天（往前 7×24 小时）、最近 30 天、今年。「图床」菜单第一项「全部图床」，列出有过图的 + 已添加的图床，筛的是「这张图在这个图床上有一份」。
- 换任何筛选条件都清空已选中的图。「还没有收藏」只在一张收藏都没有时出现；有收藏、被别的条件筛空时显示「没有匹配的图片」。
- 已选中至少一张后，单击格子或列表行变成「选中 / 取消」，不再打开详情，悬停的收藏、复制、花瓣不出现。Shift 连选跟着上一次单击走（上一次是取消，这次整段取消），只在已加载出来的图里连。
- 操作条：「收藏」在选中的全都已收藏时变「取消收藏」，不弹通知；「导出」弹系统保存框，存成 `picnexus-history-时间戳.json`，成功通知「已导出 · N 条记录」（千分位），失败通知「导出失败」+ 原因 +「请换个位置重试」（写不进所选的文件）或「请重试」（读不出记录）；「补充备份到…」列出全部已添加的图床，点了直接开始、没有进度，进行中「重新检测」「补充备份到…」不可点，结束通知「已补充备份 N 张 · 备份到X」或「N 张未能备份到X」+ 原因；「重新检测」结束通知「已重新检测 N 张」，副标题「N 条链接失效」或「均正常」。
- 批量「复制链接 ▾」：成功通知副标题「Markdown 格式，每行一个」；一条可用链接都没有时琥珀色「没有可复制的链接」；「复制哪个图床的链接」只在选中的图分布在 2 个以上图床时出现（只统计已加载出来的图）；格式比设计多「自定义」。
- 单张复制（格子、列表、灯箱、详情链接块）复制「复制时使用」那份，即使它已查出失效也照样复制；详情的图床行与批量复制不复制已失效的那份。单张复制成功不弹通知，按钮原地变「已复制」1.5 秒。
- 移除单张记录：通知「已移除记录」+ 文件名；在灯箱里移除后灯箱关掉，不跳到下一张。
- 键盘：详情开着时用方向键换图，详情跟着换；网格 ← → 按顺序走（跨行、跨天），↑ ↓ 走到上 / 下一行中线最近的那张，到顶 / 底不动；有选中时 Esc 先取消选择，再按一次才收起详情。
- 详情：「复制时使用」那份是「可能受限」时只写「⚠ 可能受限」、不出顶部提示条；提示条推荐的备份优先选「正常」的，没有就选「尚未检测」或「可能受限」的（副标题写「可改用X的备份」）；图床行「重新检测」时写「正在检测…」，检测完不弹通知。
- 详情的「移除这条链接…」：下面一行小字「只删这条链接，记录和其他备份保留」，删的是「复制时使用」那份时自动改用另一份（确认框写「移除后，复制的链接改用X」），只剩最后一份时不让删（琥珀通知「这是最后一份链接 · 如需删除，请移除整条记录」），删了不能撤销；「补充备份到…」只列已添加、还没有这张图的图床，一个都没有时不出现；「改用」备份的通知副标题「复制的链接将来自X」，点「撤销」改回去后不再弹通知。
- 列表可按「文件名」「尺寸 · 大小」「上传时间」排序：第一次点文件名 A→Z、大小与时间从大到小 / 新到旧，再点反过来；「尺寸 · 大小」按字节排。日期：列表里今年写「10月13日 08:55」、往年写「2024年8月2日 08:55」；网格日期标题除今天、昨天外一律带年份。
- 刻度条：列出全部年份，从最近一年起逐年展开有图的月份，放不下就停，更早的只写年；单击刻度也跳过去；鼠标进入右缘 64px 时出现，离开 0.3 秒后淡出；只在网格里有。
- 灯箱：单击黑色空白处关闭，单击图片放大、放大后再点关闭；大图 0.2 秒没出来才转圈，失败后隔 0.5 秒自动重试一次；首张 / 末张不画上一张 / 下一张按钮；「在浏览器打开」打开正在看的那份，「复制链接」仍复制「复制时使用」那份；换图时新图从左 / 右轻轻滑入，打开时顶栏、底栏随背景一起 250 ms 淡入，关闭时它们先淡出。只有网格里宽 ≥ 100px 的格子打开时从缩略图位置放大，窄格子与列表打开的是淡入淡出。「换个图床」菜单同标准浮层：进 200 ms 朝展开方向挪 4px 并淡入，退 140 ms 只淡出。
- 悬停 / 按下（设计稿只画了默认态）：透明底的文字、图标、筛选按钮悬停 `--pn-ghost-hover`、按下 `--pn-ghost-press`，红字的「移除记录」也一样用灰色（同菜单里的红色项）；筛选按钮生效后的实底、列表悬停行里的小按钮、详情「存放在」的浅灰底「复制」都落在浅灰底上，按浅灰底的级差（悬停 `--pn-ghost-press`、按下 `--pn-subtle-press`）；详情的「复制」按次按钮（`--pn-secondary-hover/-press`）；多选操作条是白色浮起面，按浮起按钮（`--pn-btn-soft-hover/-press`），深色下才看得出变化；筛选小标签上的 × 用半透明的 `--pn-chip-remove-hover/-press` 叠在品牌浅底上，不用灰色实底；灯箱按钮按下 `--pn-lightbox-button-press`（0.2 白）。悬停变色 100 ms；复制 → 已复制、筛选按钮变实底这类状态切换 150 ms。
- 表头的排序按钮有 24 高的悬停底色，向两侧各伸 6，文字位置不变；数字列不用等宽数字（GalleryScreen 没写，只有链接健康用了）。
- 进出场：详情栏打开从右侧滑入 250 ms，关闭 175 ms 滑出并先脱离布局（网格立刻铺满，滑走的那块盖在上面），换一张图不播；多选操作条上移 8 + 淡入 200 ms 浮出，收起 140 ms 淡出；格子的悬停层 100 ms 淡入、70 ms 淡出，选中的对勾 150 ms 淡入；列表、详情、首页的缩略图拉到后占位色块 150 ms 淡出露出图（LoadingRules ③）。「减少动态效果」时位移都去掉，操作条改成只淡入淡出。
