# 设计没画、开发时补的（设置）

> 读者：维护者，以及改这一页的 AI。阶段 7（S01–S21 K05 K10，D01–D05 弹窗提前做了）实施时按交接说明的规则自行补的做法；全部阶段做完后统一请维护者过目。标 **待拍板** 的编号汇总在 [TODO](../../../TODO.md)「界面大重构」。入口见 [README](../README.md)。

**写配置与反馈**
- 每项改动读磁盘上的最新配置、只改这一项再保存（不握表单副本）；成功在那一行闪「✓ 已保存」1.5 秒，失败红色通知「未能保存 / 原因，请重试」、界面回到磁盘值。文本类（模板、端口、压缩参数）离开输入框或停手半秒才保存。
- 开机自启、关闭到托盘：先改系统、成功才写配置；系统拒绝时开关弹回 + 红色通知；写配置失败再把系统改回去。
- 正常状态不打标记：同步状态、编辑器卡状态、最近操作照第 4 节规则不画绿点（设计稿画了，见待拍板）；出问题才是琥珀 ⚠ 或红字。
- 命令面板能搜到每一项（26 条）；Enter 切到那一组、滚到那一项并浅蓝闪 1.5 秒。托盘、首页带来的旧 tab 名照旧认（`compression` / `advanced` → 上传与链接）。

**通用 · 上传与链接**
- 外观三卡可用方向键切换。首页背景装饰存 `theme.homeDecor`，只影响快传页（空状态的装饰不受它管）。
- 自定义模板在对话框里改：点占位符插到光标处，下方用示例图实时预览；默认复制为不是「自定义」时说明这个模板何时用到；清空后存成 `{url}`。
- 压缩方案「编辑」打开对话框（名称、输出格式、质量、长边上限、缩放、小于多少不压缩、去除 EXIF），每项改完即保存；「删除方案」不弹确认、通知带撤销（原位置放回；删完切到别的分组再点「撤销」也照样放回），只剩一个时不给删；「＋ 新建方案」照默认参数新建并直接打开编辑，满 5 个置灰。缩放与长边上限同时设了时以缩放为准（沿用压缩逻辑），对话框里「缩放」只写「100 = 不缩放」。说明行写法「WebP · 质量 80 · 长边 2560 · 小于 100 KB 不压缩 · 去除 EXIF」，不缩放写「不缩放」，不去 EXIF 不写。
- 「压缩预览…」（设计没画）：照图库灯箱（G08）做成整窗深色查看器，不随主题；顶栏关闭键 +「压缩预览」+ 文件名，中间拖分割线左右对比原图与压缩后（滚轮缩放、拖动平移、双击复原），底栏写「原大小 → 压缩后 · 节省 N%」（变大时琥珀色「体积增大」）、尺寸与格式、缩放比例、「重置」「换一张…」。打开即弹出选文件窗口，没选就关；压缩失败写红字原因 +「重新选择…」。Esc 关闭。没有主按钮。

- 自动上传剪贴板：打开后后台盯着剪贴板，只传打开之后新复制的图片（Windows 看剪贴板序号，其他系统比对图片指纹），走首页的「上传到」与自动复制，和在首页粘贴一样；上传完复制的链接是文字，不会再触发上传。

**快捷键**
- 至少按住 Ctrl / Alt / ⌘（F 键可单按）；只按 Shift + 字母、按了不支持的键时不收，说明行写原因，继续录制。
- 冲突三种说法：「该组合键已用于「选择文件上传」」「该组合键已是应用内快捷键「命令面板」」「该组合键已被其他程序占用」（系统不告诉是谁，靠试注册知道），后接「，请更换」。冲突提示留到再点按钮或离开这一页，配置保持原值。
- 录制期间先注销全局快捷键（否则按到原组合键时系统直接触发上传），并拦住应用内快捷键；Esc、Tab、窗口失焦都取消；Backspace / Delete 清除，按钮写「未设置」。全局快捷键关闭时两行变灰、不能录。

**编辑器与命令行**
- 每个编辑器只选一个图床（「上传到」单选菜单：已添加且编辑器能用的图床 +「不使用」；七鱼、纳米需要浏览器，不列；一个都没有时给「去图床页添加…」）。选了图床 = 接入（Obsidian 起本机服务），选「不使用」= 停用。
- Typora 的命令写 `"…picnexus.exe" --profile typora`（命令行只认 `--profile`，设计稿写的是 `--typora`）。Typora 不放「打开 Typora」（应用拿不到 Typora 的安装位置），状态只有「尚未配置 / 已配置」。
- Obsidian 进入这一组时静默探测一次：「已连接 · 端口 N」/「端口 N 已被占用，请更换端口」/「该端口运行的不是 PicNexus 服务，请更换端口」/「服务未启动，请检查端口后点「测试连接」」，后三种琥珀 ⚠；没接入时写「尚未配置」、不给「测试连接」（设计稿一直画着），探测中写「检测中…」。端口在「更换端口…」对话框里改（一改服务就要重启，所以点「更换」才生效）。
- 命令行：「加入 PATH」= 启用命令行（导出图床配置）+ 建命令入口，「从 PATH 移除」反过来；入口已在 PATH（之前装过）而命令行没开时，状态琥珀色「已加入 PATH · 命令行尚未启用」、按钮只写「启用」；系统不支持自动加入 PATH 时按钮写「启用 / 停用」、命令用完整路径；示例命令用第一个已添加的图床；底行写「在命令中用 --service 指定图床」（命令行不带 `--service` 会报错，没有「跟随首页」）。

**备份与同步**
- 没设置云同步时卡片写「未设置云同步」+「设置后可在多台电脑间同步配置与上传记录」+「设置…」。同步方式对话框里第一份连接默认叫「坚果云」（之后「WebDAV 2」…），密码下面提示「坚果云请填写「应用密码」，不是登录密码」。「设置…」与「⋯ › 更换同步方式…」打开同一个「同步方式」对话框：名称、远程目录、服务器地址、用户名、密码（已存过时留空 = 不改，不提供「查看」）、「测试并保存」——测试通过才保存，失败把原因写在弹窗里；外部地址只收 HTTPS；存了多份连接时顶部可切换；「停用云同步」只取消选中，连接本身留着。
- 敏感字段：设置页只剩云同步密码一处，放在对话框里用普通密码框（带「显示密码」眼睛）；旧的 SensitiveField + useSensitiveDraft（看 15 秒）删除，图床页的 HostSecretField（看 30 秒）不动。
- 「配置」「上传记录」两项可勾选（存 `webdav.syncItems`，本机设置，合并时保留本机的）；都不勾时「同步」置灰、状态行写「未选择同步内容」。勾了「配置」而没设备份密码时，点「同步」先弹设置备份密码（云端配置含图床密钥）。云端配置是加密的：先用本机的密钥解，本机设过同一个备份密码就不问；解不开（新设备、云端用的是别的密码）才弹「输入备份密码」。
- 状态行：「尚未同步」/「已同步 · 2 小时前」/「正在同步配置…」「正在同步上传记录…」/「已同步 · 上传 N 条 · 下载 M 条」（为 0 的一半不写，只有配置变了写「已同步 · 配置已更新」，都没变写「已是最新」）/「同步失败：原因」红字 +「重试」；云端改动已合并进本机、回传失败时写「同步未完成：云端改动已合并到本机，回传失败（原因）」。先配置后记录，一步失败就停，已完成的照旧算数。
- 「⋯ › 用本机覆盖云端…」先确认「覆盖云端？」（设计没画，写明云端现有内容会丢失且无法撤销），覆盖勾选的配置与记录（云端记录文件损坏、合并被中止时的出路）；「用云端覆盖本机…」只覆盖配置（S14 写明上传记录不受影响）；上传记录没有「用云端覆盖本机」。合并、覆盖本机、从文件导入配置时都保留本机的同步连接与文档文件夹。
- 刷新横幅放在页标题下、任何分组都显示，直到刷新；「刷新」重新载入整个窗口，回到快传页；从文件导入配置后同一条横幅写「配置已导入，刷新后生效。」。
- 「从文件导入…」自动认出是配置还是记录（加密的或对象 = 配置，数组 = 记录），认不出写「无法识别这个文件，请选择 PicNexus 导出的配置或上传记录」；导入配置先确认（替换本机，无法撤销），导入记录直接合并。导出结果用通知说（本机操作）。没设备份密码时点「导出配置…」先出 S10（标题下也写「设置 › 备份与同步」，同 D03–D05），「先设置密码」设好后接着导出。
- 一次同步在最近操作里记两行（「同步配置」「同步上传记录 · 上传 N 条 · 下载 M 条」，为 0 的一半不写），失败时看得出是哪一步；设计稿画的是一行。最近操作只列最近 3 条，失败的红点 +「· 失败」（原因放悬停提示），其余灰点；导出写保存路径；一条都没有时整组不显示。
- 修改备份密码（D04 不画强度条）：新密码不合要求时在它下面写原因（「密码长度至少 8 位」等），免得「修改」变灰却不知为何；密码不对写「密码不正确，请重新输入」。
- 备份密码弹窗按 Dialogs.dc.html（D01–D05）重画、换成 PnDialog（阶段 9 的这部分提前做了）：多一个「解锁」模式给同步 / 导入遇到加密文件时用；启动还原输错 5 次后只剩「跳过，使用默认配置」（跳过后的做法见 README「已定的事」）；强度条满足 1–2 条琥珀、3 条以上品牌蓝。

**数据与隐私 · 关于**
- 「清理」应用缓存会连内置浏览器的 Cookie 一起清掉（下次在登录小窗里要重新登录，已保存的图床凭证不受影响）；本机记住的界面偏好（侧栏收起、提示看过没有、首屏主题）先存下、清完放回。应用缓存不写大小（缩略图在 WebView 自己的缓存里，拿不到），说明只写「缩略图与临时文件」。「清空全部记录…」沿用现有的确认 + 5 秒撤销，没有记录时置灰。「恢复默认设置…」先确认「恢复默认设置？」（设计没画）。
- 恢复默认设置 = 偏好回出厂值；保留图床（凭证、已添加 / 启用、多份图床、微博前缀）、云同步连接、文档文件夹、是否看过引导与风险说明、编辑器服务的 token；不再重新弹引导。
- 许可证写「Apache 2.0」（设计稿写 MIT，与仓库 LICENSE 不符）。
- 更新卡：没检查过写「尚未检查更新」+「检查更新」；发现新版本不写大小（检查结果里没有）；发布说明列「- 」开头的要点前 6 条；下载中写「11 / 18 MB」；「取消」= 不再安装（插件的下载停不下来），再点「立即更新」接着显示同一次下载、下完直接装；Windows 安装前、macOS / Linux「重启完成更新」前等上传传完，等待时说明行写「正在等待上传完成，完成后开始安装」（macOS / Linux 写「…，完成后重启」）；刷新横幅在时更新卡的按钮退成次要按钮（每页一个主按钮）；失败标题「更新失败：原因」，英文原文放悬停提示。

**全应用**
- 「N 天前」超过一周写日期「10月9日」（不写浏览器默认的「10/9」），首页、命令面板同一个格式器。
- 切换主题只改磁盘上最新配置里的主题，不拿启动时的配置副本回写（否则云同步 / 导入配置后切主题会把它们盖掉）。
- 像素基准只有 `tests/redesign/` 一套；设置页在 `tests/redesign/settings.visual.spec.ts`（S01–S21，两种窗口尺寸、浅深各一套）。

**待拍板**
- 设计稿在同步状态、编辑器卡状态、最近操作画了绿点，与第 4 节「正常状态不打标记」冲突；现在照规则不画。
- 「更换同步方式…」说明写「WebDAV、S3、本地文件夹」，现在只支持 WebDAV（新增两种同步方式属于扩大功能），说明只写「WebDAV」。
- 编辑器「上传到」设计稿写「跟随首页设置」「京东、Cloudflare R2」（多选），现在每个编辑器只能选一个图床（Rust 侧上传只认一个）。
- 「自动更新」说明「在后台下载新版本，下次启动时安装」做不到（插件下载的安装包不跨重启保留），现在写实际行为「启动时自动检查新版本」。
- 数据与隐私第三组标题：源文件写「重置」，交接说明 8.5 与 STATES S06 写「不能撤销」；现在照源文件。
- Obsidian 接入说明：设计写「安装 Image Auto Upload 插件，填入 http://127.0.0.1:36677/upload」，应用配套的是 PicNexus 自己的插件（填端口）；现在照实际写。
- 「重置」组的说明「以上操作无法撤销」与「清空全部记录…」确认后 5 秒内可撤销矛盾；现在照设计稿文案。
- 危险确认框的图标颜色：S14「覆盖本地配置？」画的是琥珀图标 + 红按钮，D05「关闭备份密码？」画的是红图标 + 红按钮；共用的确认框现在凡红按钮都配红图标。
- ㉗ 压缩预览是对比查看器，照灯箱做成整窗，不按「所有弹窗宽 520」做（520 宽放不下左右对比）；也可以改成 520 宽的弹窗、只放缩略对比。
- 「…」：压缩方案「编辑」、备份密码「修改 / 关闭 / 设置密码」都会打开弹窗，按第 9 节应加「…」，设计稿没加；现在照设计稿。
