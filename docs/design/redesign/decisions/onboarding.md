# 设计没画、开发时补的（引导·弹窗）

> 读者：维护者，以及改新手引导、启动还原的 AI。阶段 9（O01–O03、D01 D02）实施时按交接说明的规则自行补的做法；全部阶段做完后统一请维护者过目。标 **待拍板** 的编号汇总在 [TODO](../../../TODO.md)「界面大重构」。

**新手引导：什么时候出现**
- 配置里 `onboardingCompleted` 不为 true 时，启动后弹出（设了「启动时最小化到托盘」的，打开主窗口才看得到）。设置 › 关于「重新查看新手引导」重新打开，回到第 1 步；命令面板里同名的一项只跳到 设置 › 关于 并高亮那一行。
- 「跳过」与 Esc：不写图床与格式；第一次弹出时只记下已完成，重新打开时只关闭。点遮罩不关，免得误点丢掉选择。
- 打开时焦点落在「下一步」（不落在左下的「跳过」，免得回车就跳过）；从第 2 步回到第 1 步时「上一步」消失，焦点同样交给「下一步」。

**新手引导：选择怎么写进配置**
- 第 2 步的勾选和第 3 步的格式只在「开始使用」时一次写入，和首页「上传到 / 复制为」、托盘是同一份配置（`useUploadController.applyConfigPatch`），写完首页与托盘立即跟着变；写完回到首页。
- 第 2 步的初始勾选：第一次弹出时京东勾选、七鱼照当前配置；重新打开时两个都照当前配置（「已添加」并且启用才算勾选）。
- 取消勾选 = 停用：移出「启用」、留在「已添加」里（与首页取消勾选相同）。勾了任意一个就记下已确认公共图床风险，之后启用公共图床不再弹 P11；一个都不勾也能「开始使用」，首页显示「尚未启用图床」（H02）。
- 「微博、GitHub、Cloudflare R2、WebDAV 等 16 种图床」的数字按图床目录算（目录里除京东、七鱼以外的），目录增减时跟着变。
- 保存中「开始使用」显示加载、不可连点，「跳过」与 Esc 暂不起作用（免得覆盖刚选的）；从设置重新打开时读不出配置，不打开，通知「无法打开新手引导」+ 原因 +「请重试」；保存失败通知「设置未保存」+ 原因 +「请重试」，弹窗与选择都留着。

**新手引导：第 3 步怎么写**
- 第三种方式写实际录的「上传剪贴板图片」组合键，按平台写法（Ctrl+Shift+C / ⇧⌘C）；全局快捷键关闭或没录时改为「全局快捷键」+「在 设置 › 快捷键 中开启后，无需打开窗口即可上传剪贴板中的图片」。macOS 写「按 ⌘V 粘贴」「菜单栏菜单」。
- 默认链接格式只给 URL / Markdown；当前是 HTML 等其他格式时两个都不亮，不点就不改。分段控件用全站同一个（Controls 规格：高 26、左右 10、轨道色同设置页），设计稿这一处画的是高 28、左右 12。

**新手引导：版式**
- 弹窗 640×580、圆角 16，按钮高 32，照设计稿（引导是大弹窗，不套 520 宽的对话框规格）。窗口高度不够时弹窗限高、正文区滚动，800×600 下完整显示、不横向滚动。
- 欢迎页插图里「失效」用琥珀色、「正常」灰字不标颜色（规则 4、5；设计稿 O01 画的是红字、绿字）。
- 背景装饰只在第 1 步（欢迎页）铺在正文区，底栏不铺。插图里「Cloudflare R2」在 150 宽的行里折成两行，与设计稿同宽，按原样。
- 引导开着时拖入、粘贴都不上传（与其他弹窗一致）。应用内快捷键（Ctrl K、Ctrl O 等）照常响应，与其他弹窗开着时相同，没有单独拦。

**启动还原备份配置（D01 / D02）**
- 输错写「密码不正确，剩余尝试次数：N」；5 次用完后输入框变灰，只剩主按钮「跳过，使用默认配置」，说明写「已达尝试次数上限。跳过后加密的配置会另存在数据文件夹，可稍后在「备份与同步」中还原」。
- 「跳过」的做法见 [README](../README.md)「已定的事」；之后的通知「已使用默认配置启动」写出另存的文件名和还原办法（设置 › 备份与同步 ›「从文件导入…」输入备份密码），等新手引导关闭后才弹（免得盖住引导底栏的按钮），停留 12 秒（鼠标停在通知上时暂停）。加密配置已经不在时直接以默认配置重新加载。
- 还原成功与跳过之后都整页重新加载：等密码时主题、上传器、上传控制器读配置已失败一轮，不重新加载首页会是空白。还原成功的通知「已还原备份配置」在重新加载、启动走完（确认读得出配置）后出现。
- 「从文件导入…」认得这份另存的文件（整份存储，配置在 `config` 里）。

- 第一次弹出时点「跳过」，「已完成」没存上时不提示、只写日志，下次启动引导会再弹。点「开始使用」正在保存时「跳过」与 Esc 不起作用。
- 三个步骤圆点切换时宽度、颜色有 0.2 秒过渡；引导弹窗进场从 98% 大小、略偏下的位置浮起淡入（0.25 秒）；「减少动态效果」时改用淡入，但时长令牌同时归零，实际是直接出现（见动效待拍板 ㉞）。

**启动还原与备份密码（补）**
- 「最多 5 次」只在这次运行里计数，重启应用或点「跳过」后重新从 5 次开始。输错后清空输入框；没输入时「确认恢复」不可点；核对密码时左边的「跳过」仍可点。
- 「密码不对」以外的还原错误弹红色「还原失败 / 原因，请重试」，弹窗留着；跳过时另存文件失败弹「未能使用默认配置 / 原因，请重试」，弹窗重新出现。启动时读不出加密文件只写日志，弹窗照样出现。需要还原时即使设了「启动时最小化到托盘」也把窗口显示出来。
- 两次输入不一致时确认框下写红字「两次输入的密码不一致」（确认框里有字就判断）。设置、修改、关闭成功后分别通知「备份密码已设置 / 已修改 / 已关闭」；换密码失败通知「未能更改备份密码」+ 原因；有些图床密码搬不到新钥匙时琥珀色通知「…，但部分密码需要重新填写 / 请到图床页重新填写」（不自动消失）。
- 「解锁」模式：标题「输入备份密码」，正文「这份配置已使用备份密码加密。输入密码后继续。」，按钮「继续」，输错不限次数、写「密码不正确，请重新输入」。所有密码框按回车提交；「显示密码」点开后按钮名变「隐藏密码」。

**通知与确认框（N01，补）**
- 种类、标题、说明完全相同的普通通知 2 秒内只出一次；鼠标停在通知区时全部通知暂停计时；通知在弹窗之上；进场从下方 8px 上滑淡入（0.2 秒），离开淡出（0.15 秒）。
- 不自动消失的只有三条启动提示：「配置已重置为默认值」「部分密码已失效，需要重新填写」与上面那条「部分密码需要重新填写」。
- 撤销通知每一轮各管各的（新的一轮不会撤掉上一轮），被挤掉的按「生效」处理；点「撤销」后只说「已撤销」。断网弹琥珀「网络已断开 / 请检查网络连接」，恢复弹「网络已恢复 / 可以继续上传」。
- 确认框打开时焦点一律在「取消」（Patterns），回车不会误触危险操作，公共图床风险（P11）、明文 HTTP（P12）这类琥珀确认框也不会按回车就同意。
- 不阻塞的弹窗与确认框点遮罩就关；确认框这样关掉时「确认」「取消」都不算。窗口太矮时弹窗限高「窗口高 − 56」，内容在弹窗里滚动。确认框没指定色调时用琥珀图标块。
