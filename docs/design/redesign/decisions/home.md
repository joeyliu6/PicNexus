# 设计没画、开发时补的（首页）

> 读者：维护者，以及改这一页的 AI。阶段 3（H01–H21 HB1–3）实施时按交接说明的规则自行补的做法；全部阶段做完后统一请维护者过目。入口见 [README](../README.md)。

- 上传进行中再拖入或粘贴：提示「请稍候」，不排队（沿用现有行为）。
- 上传失败的说法（交接说明第 9 节「错误 = 原因 + 处理办法」）：认得出的原因用固定说法——网络超时、网络连接中断、登录已过期（Cookie 登录的图床）/ 凭证无效（其余）、文件超出图床大小限制、图床不支持此格式、图床服务异常；认不出的保留原文。整张失败时接处理办法，超时照设计稿写「网络超时。请检查网络后重试。」。代码在 `src/utils/uploadFailureMessage.ts` 的 `describeUploadFailure`。
- 首页在屏时，单张失败与整批结果都不弹通知（卡片上已经画出来）；在别的页面拖入或粘贴时照常弹。
- 焦点卡在第一个图床传完前显示占位图，不做本地预览。传完显示原图（复制的那份在前，加载不出来退到缩略图）；图框跟着图片的比例与原图大小变，最大 288 × 162、最小 96，不留两边的空；点图看大图（`ImageViewer`：深色铺满、按比例放到能放下的最大，点任意处或 Esc 关闭），不跳图库。
- 投放区的「选择文件…」与右边的小箭头是一个分体按钮，箭头展开「上传剪贴板图片 / 从 URL 下载…」；不用「⋯」（紧挨着「…」像重复）。
- 焦点卡「按图床复制」：点了那一枚原地变绿色「已复制」1.5 秒，即使它就是自动复制的那份；不弹通知。
- 焦点卡失败时可「换个图床」只给这一张重传（复用「上传到」浮层的单次模式）。
- 从 URL 下载：不逐行标出无效链接，沿用现有通知（链接无效 / 超过数量上限）。
- 花瓣角标数字用 9px，是字号刻度外的例外（设计稿原值，令牌 `--pn-size-petal-badge-text`）。
- 「最近上传」的「清空」只清这个列表（焦点卡留着），不删图库记录，也不跨重启记住；上传中不可清空。「清空」的文字右边与下面各行的花瓣、「更早」分隔线对齐。
- 「最近上传」也列出焦点卡里那一次（刚传的图马上能在列表里找到、复制）。点缩略图看大图（同焦点卡）；点第二行的链接直接复制，原地变「已复制」。悬停行用半透明底（`--pn-recent-row-hover`），叠在背景装饰上不发灰。
- 某个图床没传上（批量）：每个图床一行，写清几张没传上；进行中只在登录已过期时说「本批不会上传到 X」，其余失败等整批结束再报，并给「补传」（整批补传这个图床）。
- 批量缩略图点了复制：那一块盖一层绿色对勾，1.5 秒后复原（照失败那层的做法）。
- 上传前发现网络不通：这几张照样出现在首页并标成失败（「网络连接中断，请检查网络后重试」），点「重试」时没网同样按一次失败收口；不在首页时弹通知。
- 没有可用图床时拖入：标题照设计「先启用一个图床」，下一句指向此刻点得到的地方（首页指「上传到」或「启用京东图床」，别的页面先回首页）；对话框或命令面板开着时不接拖入。
- 关掉全局快捷键时，「第一次使用」的「在任意程序中按…」和渐进提示里那句都不显示。
- 从 URL 下载的提交键：Windows / Linux 写「Ctrl Enter」，macOS 写「⌘ Enter」（设计稿只画了前者）。
- 命令面板底栏跟着选中项说 Enter 做什么：图片是「复制链接」并加「Ctrl+Enter 在图库中定位」，其余是「打开」。设计稿空输入时选中图片仍写「打开」，与交接说明「图片 Enter 复制链接」矛盾，以交接说明为准。
- 命令面板的「开始链接检测」：跳到链接健康页并直接开始全量检测（正在检测时只跳过去）。
- 点「重试」立刻重传：不再等 1–8 秒退避，也不再「重试 3 次后用尽」；不弹「正在重试」通知（卡片上看得到进度）。整张重试又失败时，每个图床各写各的原因。
- 「重试失败的」只重传整张失败的图；单张重试后，第一个图床传完就复制。
- 单个图床补传成功的通知写「已补传到 X」；「修复」一词只留给链接健康。
- 交接说明「同时传 3 张」：同时处理 3 张图，每个图床也同时收 3 张（原来每个图床限 2 张，3 张都传同一个图床时第 3 张要排队）。
- 普通通知（含错误通知）默认 4 秒消失；少数调用另给了时长：断网失败、重试失败 5 秒，公共图床风险 6 秒。带「撤销」的默认 6 秒（「清空全部记录」5 秒，确认框里写明了）。
- 文件大小全应用统一写法：KB 取整，MB / GB 小于 10 时保留一位小数（「386 KB」「1.2 MB」「18 MB」），照设计稿示例。
- 批量正在传时改「复制为」的格式：等这批结束，按新格式一次复制。
- 「上传到 / 复制为 / 压缩」（首页与托盘）写不进配置：与设置页同一句红色「未能保存 / 原因，请重试」；「复制为」没存上时不按新格式重新复制。
- 「上传到」旁的 ⚠ 图标悬停说明哪个图床传不上、为什么（如「微博登录失效，暂时传不上」；Cookie 图床一律说「登录失效」，同图床页、托盘，首页设计稿写的是「登录已失效」；其他图床写「X：原因，暂时传不上」，检测没给原因时写「需要处理」）；设计没画这个说明。
- 失败卡的「换个图床」浮层里，「上传这一张」用次要按钮：失败卡的「重试」已经是这一页唯一的主按钮。
- 弹出层、菜单、子菜单离窗口边缘至少 8px（Reka 默认放不下时贴着窗口边）。
- 启动时等图床状态、配置、图库总数都读完才画首页（读完前整块留空），免得先闪一下「没有图床」。
- 「第一次使用」= 图库一条记录都没有、且这次打开后还没上传过；删光图库记录后首页回到这个样子。一开始上传就切到常规布局，焦点卡要立刻出现显示进度（STATES H01 写的「第一张传完后切换」不照做）。第一次使用的「上传到」面板列出已添加的图床，再补上还没加的京东、七鱼（点一个 = 加进来并启用，公共图床先确认风险）；整行是一个按钮；「复制为」是可点的格式菜单（不含「编辑自定义模板…」）。
- 重启后、这次还没上传过：没有焦点卡，只有投放区、三个选项和「最近上传」（直接列图库最新记录，不出「更早」分隔线）。「更早」最多 6 条；这次打开后的上传都列在上面，不限条数，直到「清空」或重启。
- 投放区「⋯」是一个菜单：「上传剪贴板图片 Ctrl+V」「从 URL 下载…」。
- 「上传到」可以一个都不勾，这时写「未选择」；此时粘贴、Ctrl+O、选择文件弹「先启用一个图床 / 请在首页「上传到」或图床页启用一个图床」（拖入走遮罩上的说法）。
- 「复制」下拉写「最先完成的链接」与「X的链接」，只列当前勾选的图床；被固定的图床取消勾选后显示退回「最先完成的链接」，固定记录不清，重新勾上后恢复。
- 焦点卡「已复制 · X」的格式菜单、批量卡的「换个格式复制」改的都是默认格式（同「复制为」），不是只换这一次。
- 关掉「自动复制链接」后：焦点卡不写「首个图床完成后自动复制链接」，传完给一个「复制 · 格式」按钮；批量卡不写「全部完成后统一复制」，也不显示「已复制」。
- 整张失败：勾了一个图床写「微博上传失败」，勾了多个写「N 个图床均上传失败」，原因取第一个失败的图床。部分失败那一行：Cookie 图床给「重新登录…」（开登录小窗，按交接说明 9.8 加「…」，批量卡同样写「重新登录…」「重新登录后补传…」），其他图床给「重试此图床」；部分失败时不显示「按图床复制」那一排（照 H05）。
- 图床不支持这个格式时这一份算「跳过」：花瓣空着、不算失败，只在传输中心写「X已跳过」。
- 「最近上传」里失败的行、批量卡里等待 / 上传中 / 失败的块不画本地缩略图（灰块或占位图标），同焦点卡。
- 「在图库中查看」（批量卡、「更早」行的「⋯」菜单）只打开图库页，不定位到这张；「更早」行的「⋯」菜单是「在图库中查看」「在浏览器打开」。
- 批量卡：失败名单最多列 3 个文件名再加「等」；整批一张没传上时加一句「剪贴板内容未改变。」；已完成的块在整批还在传时就能点着复制；「展开为列表」再点写「收起为缩略图」。
- 粘贴时剪贴板里是一条图片地址：下载后上传；下载失败是红色通知「图片链接下载失败」+ 原因（照原话）+「请检查链接后重试」。
- 拖进来的全不是图片：遮罩写「没有可上传的图片」+「包含 N 个 .x 文件，将被跳过」，松手什么也不做。拖入时按 Esc 取消这次拖入，松手不上传（H07）。
- 从 URL 下载：每次打开清空输入框，占位字「https://example.com/image.jpg」；没识别到地址时「下载并上传」不可点；最多 20 个、去重、只认 http(s)，同时下载 3 个；全部失败对话框不关，通知「URL 下载失败」+ 原因（一个地址照原话，几个都失败写「N 个地址均未能下载」）+「请检查地址后重试」；部分失败通知「部分下载失败」后照常上传并关闭。
- 快捷键：应用内 Ctrl 1–4 切到快传 / 图库 / 链接健康 / 图床，Ctrl , 设置，Ctrl+O 选择文件上传。命令面板分组「图片 / 页面 / 动作 / 设置」（空输入时「跳转」），图片最多 6 条，没有结果写「没有找到「X」」，↑↓ 到头绕回。用 Ctrl+O 或命令面板选文件也会出「更快的方法」提示。
- 整个应用不像网页：右键不弹浏览器菜单（输入框里、选中的字上照常弹），界面文字不能拖选、Ctrl+A 不把整页刷蓝（链接、路径、命令能选），缩略图和导航项拖不起来，按钮和行上的光标是箭头（只有链接是小手）；做法见 [ui-patterns.md](../../ui-patterns.md)「不像网页」。
- 命令面板的「从 URL 下载」先跳回首页再弹对话框；「切换到深色 / 浅色」把主题从「跟随系统」改成固定的那一种。
- 传输中心：标题栏的传输图标只在有进行中的任务或面板开着时出现；进行中的批量写「上传 · N 张」+ 完成数与进度条；「已完成」里单张只写文件名，整张失败才打红 ✕；没有任务时写「没有进行中的任务」。
- 不在首页时弹的上传结果通知，处理办法写「可在首页重试失败的图片」；重复拖入正在上传的文件写「N 张文件正在上传，无需重复添加」；公共图床没确认风险时指到首页「上传到」重新勾选。
- 首页画布上的透明文字按钮（「清空」「重试失败的」、「上传到 / 复制为 / 压缩」、批量卡底部三个、「⋯」）：悬停与展开 `--pn-selected`（同设计稿的展开态，半透明，不盖住背景装饰），按下 `--pn-ghost-press`，变色 100ms 过渡。
- 浅灰底的小标签（「按图床复制」的图床、「上传到」里未勾选的图床、「+N」列表里的「复制」）：悬停 `--pn-ghost-press`、按下 `--pn-subtle-press`；已勾选的图床（品牌浅底）悬停 / 按下 `--pn-chip-on-hover` / `--pn-chip-on-press`；勾选、「已复制」的切换 150ms 过渡。
- 焦点卡「✓ 已复制 · 格式」是格式菜单的触发器：悬停与展开 `--pn-pill-success-hover`、按下 `--pn-pill-success-press`；「复制 · 格式」同浅灰底标签。
- 投放区的分体按钮按次按钮的悬停 / 按下色（`--pn-secondary-hover` / `--pn-secondary-press`），箭头展开时用按下色。
- 「最近上传」里一组多张的「复制全部」是文字按钮（CopyButton 的 ghost 样式：透明底、高 26、字重 500、平时不带图标，照设计稿），复制后同样原地变「✓ 已复制」。
- 行内的蓝字链接（「管理图床 ›」「重新登录…」「补传」）悬停时浮出 `--pn-selected` 的小底（内边距 2 / 6，用负外边距抵消，文字位置与行高不变），按下 `--pn-ghost-press`。「微博失败」这类红字按钮按下用 `--pn-danger-soft-press`（与图床页的红字按钮同一个令牌）。
- 第一次使用那一行的「京东 + 再加一个备份」整组是一个按钮，悬停时两枚一起变色；「复制为 Markdown」是格式菜单的触发器，悬停浮出小底（同上）。
- 渐进提示 200ms 从上方 4px 淡入、140ms 淡出（同菜单 / 弹出层），「减少动态效果」时只淡入淡出；「知道了」悬停 / 按下 `--pn-hint-button-hover` / `--pn-hint-button-press`；圆角 12 是设计稿原值（`--pn-radius-hint`）。
- 看大图关闭时 175ms 淡出（舒展时长的 70%，同弹窗）；关闭按钮按下 `--pn-lightbox-button-press`。
- 焦点卡等链接的骨架条同骨架屏 1.4 秒明暗起伏；批量卡缩略图点了复制，绿色对勾层 150ms 淡入。
- 「上传到」的搜索框聚焦时同输入框的焦点环；底部「复制 最先完成的链接 ▾」高 26、分隔线通到浮层边缘（设计稿原值）。
